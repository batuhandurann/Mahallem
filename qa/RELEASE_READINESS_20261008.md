## Güvenlik yamasının kabul sınırı

Önceki CI'da metadata token silmenin eski URL'yi iptal ettiği varsayımı başarısız oldu. Test atlanmadı: kaynak nesneyi fiziksel silen private move düzeltildi. Yeni test ilk önce eski token'ın HTTP200 ile çalıştığını kanıtlar; validator sonrasında Admin SDK source.exists()==false, eski URL HTTP403/404 ve private nesnede token yok kabulü aranır. Geçerli alıcı gerçek byte'ları alır; üyelik kaldırıldığında unchanged validated grant yetki vermez. Blok, disabled/deleting/purging hesap, grant/path/kota ve purge temizliği de üretim handler'larıyla test edilir. İndirilmiş mevcut byte'ların geri alınabileceği iddia edilmez.

Bu testler canlı güvenlik yamasının deploy edildiğini veya mevcut canlı token'lı nesnelerin migrate edildiğini kanıtlamaz. Main push, gerçek PR merge, deploy veya secret/key değişikliği yapılmadı. QA koruması uygulandı. Canonical main `887acb5` için deploy içermeyen manuel signing [37822941864](https://github.com/batuhandurann/Mahallem/actions/runs/37822941864) çalıştırıldı ve protected Firebase config yokluğu nedeniyle FAIL oldu; signed artifact oluşmadı.
